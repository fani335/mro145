# Сайт МРО 145 АВИАКОМПОНЕНТ

Статический сайт: HTML, CSS и JavaScript без сборки и без внешних зависимостей.
Шрифты, изображения и скрипты лежат внутри проекта — сайт работает даже без интернета
и не обращается ни к каким сторонним сервисам.

## Как посмотреть

Дважды кликните `index.html` — сайт откроется в браузере.

Для более точной проверки (правильные пути, работа шрифтов) запустите локальный сервер:

```bash
cd "/Users/macbook/Desktop/claude code design/Dad:logo" && python3 -m http.server 4173
```

Затем откройте <http://localhost:4173/>. Остановить сервер — `Ctrl+C`.

## Форма обратной связи

Сейчас форма **проверяет введённые данные, но никуда их не отправляет** — так сделано
намеренно, чтобы заявки не терялись незаметно. При отправке она показывает предупреждение
о том, что доставку нужно настроить.

Чтобы включить отправку, откройте `assets/js/main.js` и впишите адрес обработчика
в константу в начале файла:

```js
var FORM_ENDPOINT = "";
```

Три рабочих варианта:

**1. Formspree — без своего сервера.** Зарегистрируйтесь на formspree.io, создайте форму,
скопируйте её адрес:

```js
var FORM_ENDPOINT = "https://formspree.io/f/xxxxxxxx";
```

**2. Свой PHP-обработчик** — если хостинг поддерживает PHP. Положите рядом файл `send.php`,
который принимает поля `phone`, `name`, `comment` и отправляет их на почту, затем укажите:

```js
var FORM_ENDPOINT = "/send.php";
```

**3. Телеграм-бот** — заявки приходят в чат. Понадобится небольшой промежуточный
обработчик, который примет данные формы и передаст их в Telegram Bot API.

После настройки проверьте: заполните форму, отправьте и убедитесь, что заявка дошла.

## Что нужно поменять перед публикацией

1. **Проверить тексты.** Часть содержания дописана — см. `CONTENT-DRAFT.md`.
2. **Политика конфиденциальности.** `privacy.html` и `en/privacy.html` — черновик
   с полями `[указать]`. Отдайте юристу, заполните реквизиты и удалите оранжевую плашку
   с предупреждением (в коде она помечена комментарием).
3. **Подключить отправку формы** — см. раздел выше.
4. **Добавить адрес электронной почты**, когда он появится: `contacts.html`,
   `en/contacts.html`, `privacy.html`, `en/privacy.html`.
5. **Проверить домен в адресах.** В `sitemap.xml`, `robots.txt` и в тегах `canonical`
   и `og:` указан `https://mro145.ru` — если сайт поедет на другой домен, замените.

## Как публиковать

Сборка не нужна: скопируйте всё содержимое папки в корень хостинга по FTP или через
панель управления. Сайт заработает сразу.

Если хостинг умеет отдавать сжатие — включите gzip или brotli для `.html`, `.css`, `.js`.
Изображения уже сжаты, шрифты в woff2 сжаты по умолчанию.

## Как править

**Текст и разделы** — прямо в HTML-файлах, любой текстовый редактор.
Одинаковые части (шапка, подвал) продублированы на каждой странице: правку в шапке
нужно повторить во всех 12 файлах.

**Цвета, шрифты, отступы** — в начале `assets/css/style.css`, блок `:root`.
Фирменный синий `#1670c6` взят пипеткой из логотипа.

**Изображения** — `assets/img/`. У каждой фотографии два файла: `.webp` (грузится
в современных браузерах) и `.jpg` (запасной вариант). При замене готовьте оба
или оставьте только `.jpg`, убрав строку `<source>` в разметке.

Логотипы в `assets/img/`:

| Файл | Что это |
|---|---|
| `logo-wide.png` | Знак + надпись, синий на прозрачном фоне — шапка сайта |
| `logo-wide-white.png` | То же белым — подвал и тёмные блоки |
| `logo-mark.png` | Квадратный знак без надписи — аватарки, из него сделаны фавиконки |
| `favicon-64.png`, `favicon-180.png` | Иконка вкладки и иконка на экране «Домой» |
| `og-image.jpg` | Картинка для превью при отправке ссылки в мессенджер |

Все они вырезаны из вашего `logo_1.jpeg` — исходник лежит в корне проекта.

## Технические детали

- Адаптив: брейкпоинты 1080 / 900 / 680 px, мобильное меню-бургер.
- Доступность: пропуск к содержимому, видимый фокус, `aria`-атрибуты на меню
  и аккордеоне, осмысленные `alt` у всех изображений.
- SEO: уникальные `title` и `description` на каждой странице, `canonical`,
  связки `hreflang` между русской и английской версиями, разметка `schema.org/LocalBusiness`,
  Open Graph, `robots.txt`, `sitemap.xml`.
- Анимации отключаются, если в системе включён режим уменьшения движения
  (`prefers-reduced-motion`).
- Есть стили для печати: при печати страницы шапка, меню и формы скрываются.
